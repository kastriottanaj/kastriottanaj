Hey — this file is the template for an issue. Rename it, write your own, set
`draft: false`, push, then send it. Delete this paragraph when you do.

Everything you write here becomes both the email and the web version at
`/newsletter/archive/<filename>/`, so write it once.

## What renders well in email

Headings, paragraphs, **bold**, [links](https://kastriottanaj.com/), and lists:

- Short lines beat long ones — most people read this on a phone.
- One idea per issue. The archive is where the depth goes.
- End with a single thing to try this week.

> A pull quote reads well too, if you have one worth pulling.

Keep images rare and hosted on the site — some clients block them by default,
so the issue has to make sense with every image switched off.

## What to try this week

Pick the one page that already ranks 5th–15th for something you care about,
and improve it rather than writing a new one. That is usually the cheapest
traffic on the table.
