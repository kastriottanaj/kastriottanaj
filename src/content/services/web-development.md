## What this is

Websites built the way a site meant to rank should be built: real HTML delivered fast,
with the technical SEO handled at the foundation instead of retrofitted by a plugin six
months later.

## How I work on it

Static-first. Pages are rendered to HTML at build time, so there is no server work
between a crawler asking for a page and getting it. JavaScript ships only where something
on the page actually needs it — a menu, a form — rather than as a framework runtime on
every page.

The things that usually get left until launch week are done from the start: structured
data, canonical URLs, sitemap, image optimisation, and lead capture that goes somewhere
you control.

## Who it suits

Businesses whose current site is slow, hard to update, or structurally incapable of
ranking — one page trying to cover six services, or a page builder generating markup that
no amount of on-page work can rescue.
